# MelodyHub - Music Streaming UI

MelodyHub is a responsive Spotify-inspired music streaming web application built using HTML, CSS, and JavaScript.

## Features
- Responsive music player UI
- Playlist cards
- Album section
- Play/Pause controls
- Volume control
- Interactive seekbar
- Modern dark-themed interface

## Tech Stack
- HTML5
- CSS3
- JavaScript
